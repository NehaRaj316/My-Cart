## Reporting a Vulnerability

Contact Email:rajn76411@gmail.com
Response Timeline:within 48 hours
Disclosure Policy:

Please do not open public GitHub issues to report security vulnerabilities. 

* **Responsible Disclosure:** Report security issues privately via email first to allow us time to fix the issue before public disclosure.
* **Fix & Release:** We will investigate valid reports, issue a security patch, and release an update as soon as possible.
* **Public Acknowledgement:** Credit will be given to the reporter in the release notes once the patch is published (unless you request to remain anonymous).
